Firebase online access is intentionally disabled for this portfolio demo.

If this Firebase project was previously configured with public test rules, replace
those rules in the Firebase console with the deny-all rules below and publish them.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if false;
    }
  }
}

The website now uses browser localStorage only. A production version would need
Firebase Authentication and role-based Firestore Security Rules.
