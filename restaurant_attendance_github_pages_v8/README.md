# Restaurant Attendance Demo — App Source

This folder contains the static application published by the repository's root `index.html`.

The app is intentionally local-only: it uses browser `localStorage`, has no Firebase connection, and does not collect shared employee data. Use the role buttons on `login.html` to explore it without a password.

See the [repository README](../README.md) for features, setup instructions, security notes, and the production roadmap.
